이모지 와르르 - 무료 웹사이트

1) index.html을 더블클릭하면 내 컴퓨터에서 바로 실행할 수 있습니다.
2) 인터넷에 공개하려면 GitHub 계정으로 로그인한 뒤 새 Repository를 만듭니다.
3) index.html 파일을 업로드하고 Settings > Pages에서 배포를 켭니다.
4) 배포가 끝나면 GitHub Pages가 알려주는 주소로 접속하면 됩니다.

이 버전은 외부 API 없이 브라우저에서 작동하는 규칙 기반 변환기입니다.
따라서 무료이고 API 키가 필요 없지만, AI처럼 모든 문맥을 이해하지는 않습니다.
